# 🐌 Copa Caracol

Um jogo de corrida multiplayer local desenvolvido na Unity, com foco em partidas rápidas, modos variados e pistas caóticas cheias de obstáculos.

---

# 🎮 Sobre o jogo

**Copa Caracol** é um jogo de corrida arcade 2D onde dois jogadores competem em pistas temáticas utilizando diferentes modos de jogo.

O projeto foi desenvolvido utilizando:

- Unity
- C#
- Sistema de multiplayer local (split-screen)
- Física 2D
- Interface dinâmica
- Seleção de mapas e modos de jogo

# 🚗 Funcionalidades

## 🏁 Modos de jogo

- Corrida Clássica
- Eliminação

---

## 🗺️ Seleção de mapas

Cada pista possui sua própria scene e ambientação.

Atualmente o jogo conta com 3 mapas:

- Jardim
- Lamaçal
- Piquenique

---

## ⚡ Sistema de Boost

- Barra de boost para os 2 jogadores
- Ativação por tecla específica
- Disponível apenas para quem estiver em último lugar

---

## 📷 Sistemas de câmera

### Corrida Clássica

- Split-screen para multiplayer local

### Eliminação

- Câmera dinâmica focada no líder
- Eliminação automática de jogadores fora da câmera

---

## 🚂 Obstáculos Dinâmicos

- Objetos móveis seguindo trajetórias definidas
- Sistema reutilizável baseado em waypoints

---

## 🎨 Interface

- Menu principal
- Seleção de modos
- Seleção de mapas
- Countdown de largada
- Tela pós-corrida
